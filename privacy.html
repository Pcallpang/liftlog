개인정보처리방침

시행일자: 2026-08-06

1. 서버에 저장되는 개인 데이터 없음

더드미요의 운동 추천은 회원가입, 로그인, 서버 데이터베이스가 없는 앱입니다. 입력한 프로필(키·체중·3대 중량), 운동 기록, 대화 내용, API 키는 전부 사용 중인 브라우저의 localStorage에만 저장되며, 이 서버는 해당 정보를 저장하지 않습니다.

2. AI 대화 기능 이용 시 전달되는 정보

대화 탭에서 AI 트레이너와 대화하려면 사용자가 직접 발급받은 Claude(Anthropic) 또는 Gemini(Google) API 키를 입력해야 합니다. 대화를 전송하면 입력한 API 키와 대화 내용, 운동 기록 요약이 이 서버를 거쳐 해당 AI 제공사(Anthropic 또는 Google)로 전달되어 응답을 생성합니다. 서버는 이 요청을 그대로 중계만 하며 API 키나 대화 내용을 별도로 저장하지 않습니다.

3. 외부 서비스

  • 글꼴(Jua)을 Google Fonts에서 불러오며, 이 과정에서 사용자의 IP 주소가 Google로 전달될 수 있습니다.
  • AI 대화 기능 이용 시 위 2항과 같이 Anthropic 또는 Google에 요청이 전달됩니다.
  • 쿠키, 방문 추적 스크립트, 광고 SDK는 사용하지 않습니다.

4. 데이터 삭제

설정 화면의 "데이터 초기화" 버튼을 누르거나 브라우저에서 이 사이트의 저장된 데이터를 지우면 프로필·기록·대화·API 키가 즉시 완전히 삭제됩니다. 서버에는 남는 사본이 없습니다.
